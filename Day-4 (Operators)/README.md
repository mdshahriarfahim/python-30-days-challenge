# 🐍 Day 04 - Python Operators

Today I learned about Python operators and how they are used to perform different operations on data.

---

## 📚 Topics Covered

### 01. Arithmetic Operators
- Perform mathematical calculations such as addition, subtraction, multiplication, division, modulus, exponentiation, and floor division.

### 02. Assignment Operators
- Assign values to variables and update existing values.

### 03. Comparison Operators
- Compare two values and return a Boolean result (`True` or `False`).

### 04. Logical Operators
- Combine multiple conditions using logical operations.

### 05. Identity Operators
- Check whether two variables refer to the same object in memory.

### 06. Membership Operators
- Check whether a value exists in a sequence or collection.
